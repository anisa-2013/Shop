# Shop API — дипломный проект

REST API для интернет-магазина, разработанный на Django и Django REST Framework.

Проект позволяет пользователям регистрироваться, просматривать каталог товаров, работать с корзиной и оформлять заказы. Для авторизации используется JWT.

## Возможности проекта

- Регистрация пользователей
- JWT-аутентификация
- Получение и обновление токенов
- Просмотр категорий
- Просмотр товаров
- Добавление товаров в корзину
- Изменение количества товаров в корзине
- Удаление товаров из корзины
- Создание заказов
- Просмотр заказов пользователя
- Автоматическая очистка корзины после оформления заказа
- Административная панель Django
- Swagger-документация API

## Локальный запуск

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Выполните миграции:

```bash
python manage.py migrate
```

Запустите сервер:

```bash
python manage.py runserver
```

После запуска Swagger доступен по адресу:

`http://127.0.0.1:8000/api/docs/`

## Основные API endpoints

### Авторизация

- `POST /api/auth/register/` — регистрация пользователя
- `POST /api/auth/login/` — получение JWT-токенов
- `POST /api/auth/refresh/` — обновление access-токена

### Каталог

- `GET /api/categories/` — список категорий
- `GET /api/products/` — список товаров

### Корзина

- `GET /api/cart/` — просмотр корзины
- `POST /api/cart/items/` — добавление товара
- `PATCH /api/cart/items/{id}/` — изменение количества товара
- `DELETE /api/cart/items/{id}/` — удаление товара

### Заказы

- `GET /api/orders/` — список заказов пользователя
- `POST /api/orders/` — создание заказа

## Переменные окружения

Для локального запуска и развертывания проекта используются следующие переменные окружения:

- `SECRET_KEY` — секретный ключ Django
- `DEBUG` — режим отладки (`True` или `False`)
- `ALLOWED_HOSTS` — список разрешённых хостов
- `DATABASE_URL` — URL подключения к базе данных PostgreSQL
